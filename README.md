Smart Exit Guardian (SEG)
Overview

Smart Exit Guardian is an ESP8266-based smart assistant that reminds users of essential items before leaving home. It also provides live weather updates and voice guidance.

Features
Voice-assisted reminders
Destination-based checklist
Live weather using OpenWeather API
OLED Display
Low power operation
Easy navigation using push buttons
